# Generador de Guiones Publicitarios V3

Cambios principales:
- El público objetivo NO se inserta literalmente en el speech.
- Problema/deseo se transforma en lenguaje publicitario natural.
- Diferenciador se transforma en una propuesta de valor, evitando copiarlo tal cual.
- Mejoras para clínicas dentales y otros rubros frecuentes.
- Cinco ángulos distintos según el objetivo.
- Revisión final de frases rígidas o poco naturales.

Para actualizar GitHub Pages:
1. Descarga y descomprime el ZIP.
2. Sube el nuevo `index.html` a la raíz del repositorio.
3. Haz Commit changes en la rama main.
